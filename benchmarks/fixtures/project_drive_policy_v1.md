# Development Workstation Drive Policy

The workstation contains several local storage locations.

The Local AI system may use the primary project storage locations for source
code, models, caches, datasets, generated files, and archives according to the
configured filesystem layout.

The /ssd2 drive is reserved exclusively for games and emulation.

Local AI models, datasets, caches, benchmark data, and generated project files
must not be placed on /ssd2.

Unrelated note: benchmark reports should preserve historical model results.
